How it works

1. CaptureImage uploaded or taken from webcam.
2. DetectYOLOv8n finds defects and classes.
3. DecideAny defect above the threshold = FAIL.
4. LogResult and annotated image saved to SQLite; export as CSV.

Limitations

  • Small public dataset (320 train / 80 validation images), single split and seed, no separate test set.
  • Tiny defects and faint thin thread errors are the main misses (see Error review).
  • Numbers come from the validation split. Real mill conditions need retraining on local data.
